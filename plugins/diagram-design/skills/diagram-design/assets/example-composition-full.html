Certainty · assembled from the catalog

Six interchangeable parts live in one shared catalog. Certainty uses three of them — ingest, engine, ui — plus one bespoke component built only for this product. The correspondence is the matching number, not a line back to the catalog.

NO SPAGHETTI

Numbers, not edges

Four connectors from catalog parts to one assembly box would violate the no-overlap rule fast. A matching number in both places does the same job with zero lines.

The catalog stays uniform

  • Same size, same treatment, all six parts
  • Uniformity is what "interchangeable" looks like
  • Which parts got used shows up in the assembly, not by dimming the catalog

The bespoke part is the point

Every honest composition has a piece that isn't from the catalog. Award rules gets full node weight and the one accent in the diagram — omitting it would make the assembly look more reusable than it really is.
