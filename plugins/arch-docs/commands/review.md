---
description: Review the set as a set, not page by page
argument-hint: [page number for a single-page critique]
---

Use the `arch-docs` skill. With a page number, load `references/08-page-critique.md` and critique that page. With no
argument, load `references/09-set-review.md` and run the seven set-level checks, including the subtitle-only read
and the budget check.

Report findings as a numbered list with the pages each one touches. Do not fix anything until the owner says which
findings to take.
