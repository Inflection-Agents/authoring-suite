Use the `arch-docs` skill and load `references/01-kickoff.md`.

Establish the frame: audience, deliverable, sources, the problem the set has to make visible, and the process
rules. Then play back what you heard as two numbered walkthroughs, one unit of work and one change moving end to
end, and name the single assumption you are leaning on. Ask the owner to correct it before you ask anything else.
