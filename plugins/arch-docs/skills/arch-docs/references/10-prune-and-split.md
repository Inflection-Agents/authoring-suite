# 10 Prune and split

**Goal.** Cut the wide draft down to the set one audience needs for one occasion.
**Produces.** A keep, cut and merge list with reasons, then the pruned and renumbered set.
**Gate.** The owner has approved the three lists before any page is renumbered or removed.

Pruning is where the set gets good. Drafting wider than needed only pays off if this phase actually runs, because
pruning is the only reliable way to learn which diagrams were carrying the argument.

Take the audience and the occasion from the kickoff frame, and say them back before you start: a 40-minute review, a
proposal appendix, an onboarding pack. Then produce three lists, before touching anything.

## Keep

Each page, with the one sentence of the argument it carries. When two pages carry the same sentence, they are not both
keeps.

## Cut

Each page, with what is lost by cutting it and where that content goes instead, if anywhere. Apply these four tests and
name which one applies:

- it exists for completeness rather than for a point
- its point is already made by a page that is staying
- it shows a component the audience does not make decisions about
- it needs more explanation than the fact is worth

## Merge or split

Pages that should become one, and pages that should become an overview plus a detail. Splitting is right when a page is
over budget and every element on it is load-bearing. Pruning is right when a page is over budget because it is being
thorough.

## Then say what the cut does to the argument

Give the new manifest order and say what the pruned order does to the argument. A cut set usually needs one or two
subtitles rewritten, because the page they leaned on is gone. Name those subtitles; the rewrite itself belongs to
[11](11-language-pass.md).

## After the owner approves

Renumber, rebuild, regenerate the index, and run the set checks. Keep the cut pages in the repository rather than
deleting them, so the owner can put one back. Numbers move during a prune, so any later reference to a page maps by slug
against the current manifest, the way [12](12-late-change.md) does.
