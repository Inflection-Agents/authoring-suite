# Muse White Paper

## Init gate: voice sheet first

Before anything else, check `voice-sheet.md`. If it is absent or holds
fewer than 3 entries, run elicitation per `references/elicitation.md`
first and write the sheet before drafting. On a re-run with a sheet
present, report the habits found and ask which to revisit; never wipe
an existing sheet.

One spine, two renders. See `references/budgets.md` for the area math,
`references/elicitation.md` for voice capture, `references/revision-loop.md`
for the capped revision loop. Copy `assets/spine.template.md` to start.
