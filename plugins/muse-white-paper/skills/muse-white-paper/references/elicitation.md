# Voice Elicitation

Three passes, all stored. No prose generates before the sheet exists.

## Pass 1: Talk-throughs

Run three 15-minute talk-throughs, one per register, in this order:

1. Opinion: what the owner believes and what they reject.
2. Explainer: how the owner teaches a hard idea to a smart newcomer.
3. Work story: what happened on a real job, told start to finish.

Record all three. Transcribe verbatim; do not smooth the wording.

## Pass 2: Extraction

List candidate habits heard in the transcripts. Keep only
cross-register habits: a habit reaches the sheet if it appears in all
three registers. A habit heard in one topic alone never reaches the
sheet; note the exclusion and drop the entry.

## Pass 3: A/B pairs

Write 20 to 30 sentence pairs, one habit per pair. Each pair holds a
liked line the owner kept and a rejected line that is the same line
with exactly that habit removed or broken and nothing else changed.
Log each reject as the counter-example in the pair; the rejected line
is the record of the habit's edge.

## Pass 4: Deletion check

Strip each habit from its liked line in turn. If the line stays strong
without it, the habit is not load-bearing; drop it. Only habits whose
removal makes the line go flat survive.

## Sheet write

Write survivors to `voice-sheet.md` per
`references/voice-sheet-schema.md`: one entry per habit with habit
name, liked line, rejected line, and scope note naming the registers
observed. Later draft-vs-rewrite pairs overrule the sheet on conflict
without a sheet rewrite (see `references/edit-pairs.md`).
